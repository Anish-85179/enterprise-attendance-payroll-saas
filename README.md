# Enterprise Attendance & Payroll SaaS Suite (Block 4)

An advanced, high-ticket B2B Excel solution designed to replace expensive SaaS subscriptions for mid-sized corporate clients ($600–$950+ portfolio pricing tier). 

---

## 🏗️ 4-Sheet Enterprise Architecture (Left-to-Right)

1. **`Control_Dashboard`**
   * Executive KPI command center tracking total active staff, average attendance rates, overtime hours, and total monthly payroll outflow.
   * Features dynamic period control selectors for Month and Year reporting.

2. **`Matrix_Attendance_Tracker`**
   * Visual day 1–31 grid utilizing status checkmark validations (`✔`, `❌`, `L`).
   * Powered by custom conditional formatting (emerald green for present, crimson red for absent) and automated summary count columns.

3. **`Payroll_Calculator` (Automated Payroll Engine)**
   * Cross-sheet integration engine linking live attendance counts to base salaries and employment types (Full-Time vs. Contract).
   * Automatically computes pro-rated gross earnings, overtime pay, individual tax bracket withholdings, and final net cash disbursements.

4. **`Master_Roster`**
   * Centralized backend employee directory containing unique IDs, departments, designations, salary tiers, tax brackets, and bank routing numbers.

> As part of our high-ticket enterprise solution delivery, this workbook has been engineered with an **interactive simulation layer** designed to showcase real-time cross-sheet data mapping and multi-period reporting capabilities.

> 2. **Sheet-by-Sheet Impact Breakdown:**
>    * **`Master_Roster`:** 100% Static core database maintaining absolute data integrity.
>    * **`Matrix_Attendance_Tracker`:** Dynamic simulation layer utilizing randomized distribution logic for filtering tests.
>    * **`Payroll_Calculator`:** Downstream calculation engine dynamically responding to active attendance inputs.
>    * **`Control_Dashboard`:** Aggregated metric display reflecting real-time updates from underlying calculation engines.
> 3. **Purpose of Interactivity:** Volatile simulation functions enable live dropdown filtering and cross-sheet responsiveness during evaluation.
> 4. **Production Deployment Guarantee:** Demonstration simulation layers are removed for final client delivery, replaced with verified historical logs or manual HR check-ins to ensure a **100% static, deterministic, and audit-ready enterprise system**.

## 🚀 Usage & Portfolio Deployment
1. Download `Block4_Enterprise_Attendance_Payroll_Suite.xlsx`.
2. Navigate to **`Master_Roster`** to manage employee compensation and tax brackets.
3. Use the **`Matrix_Attendance_Tracker`** to log monthly attendance via dropdown toggles.
4. Review calculated disbursements instantly on the **`Payroll_Calculator`** and executive metrics on the **`Control_Dashboard`**.
